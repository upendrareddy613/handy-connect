========================================================================
   HANDYCONNECT - HOW TO RUN ON ANY LAPTOP OR COMPUTER
========================================================================

PRE-REQUISITES (Required on the other laptop):
1. Python 3 (version 3.10 or higher) -> Download from: https://www.python.org/
   IMPORTANT: During Python installation, make sure to check 
   "[X] Add Python to PATH"

2. Node.js (version 18 or higher) -> Download from: https://nodejs.org/
   (Choose the LTS Recommended version)

------------------------------------------------------------------------
HOW TO RUN:
------------------------------------------------------------------------

METHOD 1: THE 1-CLICK AUTOMATIC WAY (EASIEST)
---------------------------------------------
1. Extract this entire zip file to any folder on your laptop.
2. Inside the extracted folder, double-click:
      "RUN_ON_ANY_LAPTOP.bat"
3. That's it! It will automatically:
   - Check and install required Python packages
   - Check and install required React frontend packages (on first run)
   - Start the backend on port 8000
   - Start the frontend on port 5173
   - Open your browser to http://localhost:5173/

------------------------------------------------------------------------
METHOD 2: THE MANUAL COMMAND PROMPT WAY
------------------------------------------------------------------------

A. Start the Backend:
1. Open a Command Prompt (cmd) window.
2. Navigate to the backend folder:
   cd backend
3. Install backend packages:
   pip install -r requirements.txt
4. Run the server:
   python manage.py runserver 8000
   (Keep this cmd window open)

B. Start the Frontend:
1. Open a SECOND Command Prompt (cmd) window.
2. Navigate to the frontend folder:
   cd frontend
3. Install frontend packages (only needed on first run):
   npm install
4. Run the frontend:
   npm run dev
   (Keep this cmd window open)

5. Open your browser and go to:
   http://localhost:5173/
